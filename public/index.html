IF SOMETHING ISN’T WORKING

Quick troubleshooting

Start with the symptom. These checks won’t change your files or settings.

My phone cannot open the ThinkPad address

Confirm Phone Bridge is running on the ThinkPad, Tailscale is connected on both devices, and the phone is signed into the same Tailscale network. Use the full secure address shown above, including port 8788.

The browser says the connection is not private

Install the Phone Bridge root certificate on the phone and enable full trust in certificate settings. Then close and reopen the browser. Do not bypass a certificate warning.

My pairing code expired or was not found

Start pairing again on your phone. A fresh code will open in Notepad on the ThinkPad and expire after five minutes.

My phone was connected but now shows reconnecting

Check the ThinkPad is awake and the server is running. Restore the Tailscale connection, then reopen Phone Bridge. If the session has expired, pair the phone again.

Storage is full or an upload fails

Phone Bridge allows up to 250 MB per file and 10 GB total storage. Check the File Library before removing anything; delete only files you no longer need.

Help & privacy

Cloud workspace
1Sign in with your PhoneBridge account. Your account session is stored by Supabase; local desktop session exchange is not used.
2Choose Pairing, create a six-digit code and enter it in the Windows PhoneBridge Agent. Codes expire after five minutes and are single-use.
3Choose Computer for system information, workspace file listing and text file operations supported by the connected Agent. Write and folder creation require explicit approval.

The legacy Drive, browser file transfer, synchronization, notes, AI pages and audio/video streaming still depend on local-only services and are not active in the cloud app. Screen sharing, mouse control and keyboard control are not exposed. Cloud APIs enforce account ownership; service-role credentials remain server-side.
