IF SOMETHING ISN’T WORKING

Quick troubleshooting

Start with the symptom. These checks won’t change your files or settings.

My phone cannot open the ThinkPad address

Check that both devices have internet access and that the PhoneBridge background connector is running on the computer. PhoneBridge pairs through the cloud, so the phone and computer do not need to be on the same Wi-Fi or Tailscale network.

The browser says the connection is not private

The cloud website uses HTTPS and does not require a local certificate. If the browser reports a certificate warning, check the website address and device date/time; do not bypass the warning.

My pairing code expired or was not found

Start a new pairing on your computer, then approve its new code on your phone. Codes expire after five minutes.

My phone was connected but now shows reconnecting

The green Cloud online label only confirms the website is reachable. Check Paired devices: the computer is connected only when it shows Online from a recent computer check-in. If it is Offline, restart the PhoneBridge background connector, then tap Pair this computer.

Storage is full or an upload fails

Phone Bridge allows up to 250 MB per file and 10 GB total storage. Check the File Library before removing anything; delete only files you no longer need.

Help & privacy

Cloud workspace
1Sign in with your PhoneBridge account. Your account session is stored by Supabase; local desktop session exchange is not used.
2On your computer, tap Pair to generate a six-digit code. Enter it on your phone and tap Connect. Codes expire after five minutes and are single-use.
3Open a paired computer to see its online status and last check-in. The background connector is used only for enrollment and connection status.

The legacy Drive, browser file transfer, synchronization, notes, AI pages and audio/video streaming still depend on local-only services and are not active in the cloud app. Computer tasks, task history, screen viewing, mouse control and keyboard control are not available in this workspace. Cloud APIs enforce account ownership; service-role credentials remain server-side.
